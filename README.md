**Поисковик торрентов** — современное, быстрое и удобное настольное приложение для Windows, объединяющее поиск фильмов, сериалов и телешоу по крупнейшим русскоязычным каталогам (RuTracker, RuTor, NNM-Club, MegaPeer, TorrentKino) в едином интерфейсе.

Больше не нужно вручную открывать десятки сайтов: приложение параллельно опрашивает базы, группирует результаты по фильмам с официальными постерами, подтягивает рейтинги **Кинопоиска** и **IMDb** с прямыми ссылками на отзывы зрителей, позволяет мгновенно фильтровать раздачи по разрешению и цветовому диапазону видео, по году выпуска, сезонам/частям и источникам, запускать онлайн-просмотр видео без ожидания скачивания и обеспечивает стабильный доступ через **встроенный обход блокировок для России**.

## ✨ Ключевые возможности

- 🌐 **Встроенный обход блокировок для России:**
  - Встроенные скоростные шлюзы (Cloudflare Worker и резервный шлюз Supabase Edge) обеспечивают надёжный доступ ко всем каталогам без установки сторонних VPN.
- 🖼️ **Режимы отображения результатов:**
  - **Режим «Таблица» (сетка постеров):** визуальное представление с постерами высокого разрешения, цветными бейджами качества и компактной технической информацией.
  - **Режим «Список»:** классический компактный табличный вид с подробными данными (размер, дата, сиды, личеры, источник).
- 🗂️ **Внутренняя карточка фильма и раздачи:**
  - Рейтинги **Кинопоиска** и **IMDb** с количеством оценок.
  - Прямые ссылки на **отзывы зрителей** на Кинопоиске и IMDb (открываются в браузере в один клик).
  - Удобные действия: открытие воспроизведения, копирование magnet-ссылки, скачивание `.torrent` и переход на страницу трекера.
- 🎙️ **Голосовой поиск на русском языке:**
  - Быстрый ввод названия фильма голосом через микрофон с автоматическим распознаванием.
- 🎬 **Онлайн-просмотр без скачивания (TorrServer):**
  - Поддержка стриминга торрентов на лету через **TorrServer** в связке с VLC, Media Player Classic (MPC-HC) или веб-плеером.
- 🚀 **Параллельный опрос 5 ведущих каталогов:**
  - **RuTracker** — поддержка авторизации (вход через встроенное безопасное окно с автосохранением сессии или ручной ввод Cookie).
  - **RuTor** — открытый каталог с актуальными пирами и magnet-ссылками.
  - **NNM-Club** — автоповтор при временных ошибках трекера и прямая загрузка торрентов.
  - **MegaPeer** — быстрый поиск с прямыми торрент-файлами и сидами.
  - **TorrentKino** — каталог фильмов и сериалов.
- ⚡ **Мгновенные локальные фильтры (без повторных запросов в сеть):**
  - Разрешение: **480p**, **720p**, **1080p**, **2160p (4K)**.
  - Динамический диапазон: **SDR**, **HDR**, **Dolby Vision**.
  - Фильтр по годам выпуска и источникам.
  - Сортировка по релевантности, сидам, размеру и дате публикации.
- 🎨 **Удобный интерфейс:**
  - Контрастная плоская иконка приложения.
  - Отзывчивый темный интерфейс.
  - Окно карточки остаётся открытым при запуске воспроизведения.
- 🔒 **Конфиденциальность и безопасность:**
  - Без рекламы, скрытых процессов и телеметрии.
  - Все сессии, история поиска и настройки сохраняются строго локально на вашем компьютере (`%APPDATA%`).
